# LOT Travels Website

Lonely Planet-style multi-page website for **LOT Travels** (लोट ट्रेवल्स) — taxi & tour service in Darjeeling, West Bengal.

- 7 pages: Home, Destinations, Itineraries, Taxi Services, Travel Guide, About, Book a Trip
- WhatsApp booking forms, entry popup, animated counters, scrolling marquee
- Fully responsive, SEO + LocalBusiness schema

Live: deploy `index.html` as a static site (all routes are client-side).
